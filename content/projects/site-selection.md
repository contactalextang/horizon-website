## 项目概述

智囊团是一个单文件 HTML 应用，专为新加坡 F&B 选址与实物投资决策设计。无需安装，浏览器直接打开即用。

## 8 个 AI 智囊角色

包含总指挥、F&B 专家、财务顾问、风险评估、合规检查、市场情报、AI 顾问、LP 融资顾问，覆盖投资决策的每个关键维度。

## 核心功能

- **7 步决策工作流**：自动注入项目背景上下文，从市场调研到 LP 融资全流程引导
- **自由对话模式**：随时切换至任意智囊角色深入探讨
- **深度搜索**：联网调研功能，获取实时市场数据
- **知识资产库**：备忘录库、案例库、市场库 CRUD 管理
- **PDF 报告导出**：A4 格式，含封面、目录、分析页、封底
- **多 AI 引擎**：同时支持 Claude API / Gemini API / Kimi API，Keys 存储于本地，不上传服务器
