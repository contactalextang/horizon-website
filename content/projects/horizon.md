## 功能特点

- 从 HackerNews、Reddit、GitHub、RSS、Telegram、Twitter 等 8 个数据源自动采集
- 使用 Claude / GPT / Gemini 等 AI 模型对每条内容评分（0-10）、生成摘要
- 支持背景信息富化（网络搜索 + AI）和社区讨论收集
- 生成中英文双语 Markdown 日报
- 支持邮件投递和 Webhook 推送（飞书/DingTalk/Slack/Discord）
- 内置 MCP 服务器接口
