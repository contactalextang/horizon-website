## [Tailcat – Netcat-like tool over Tailscale's data plane](https://github.com/tailscale/tailcat) ⭐️ 8.0/10

Tailcat is an open‑source utility that provides netcat‑style communication over Tailscale’s data plane, allowing peer‑to‑peer connections without using Tailscale’s control plane. By exposing Tailscale’s secure, NAT‑traversed WireGuard tunnels as a simple netcat‑like interface, Tailcat lowers the barrier for developers to build P2P scripts and applications, potentially expanding the ecosystem of Tailscale‑based tools. Tailcat uses Tailscale’s magicsock (WireGuard + DERP) for encrypted, hole‑punched connections and requires a tailcat relay service only for initial bootstrapping; it works without the full Tailscale control plane and is released under the same open‑source license as Tailscale.

hackernews · Hacker News RSS · Aug 26, 17:42 · [Discussion](https://news.ycombinator.com/item?id=49452990)

**Background**: Tailscale separates its network into a control plane that manages keys, DNS, and node information, and a data plane (magicsock) that forwards encrypted WireGuard packets and handles NAT traversal via DERP relays. Netcat is a classic networking utility that reads and writes data across TCP or UDP connections, often used for quick debugging or file transfers. By exposing only the data plane, Tailcat lets users create netcat‑style pipes over Tailscale’s secure, peer‑to‑peer tunnels without dealing with the control plane’s complexity.
