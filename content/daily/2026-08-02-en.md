This update inspired Simon Willison to create mcp‑explorer and datasette‑mcp tools. The stateless approach removes the need for server‑side session storage, making MCP easier to scale in web applications and usable by smaller language models that run on laptops. It renews developer interest in a standardized tool‑calling interface for LLM agents. The new spec replaces the initialize + tools/call two‑step flow with a single POST that includes MCP‑Protocol-Version: 2026-07-28, Mcp‑Method: tools/call, and Mcp‑Name headers, while client information is placed inside the JSON‑RPC _meta field. Simon built three implementations this week to demonstrate the simplicity.

**Background**: The Model Context Protocol (MCP) was introduced by Anthropic in November 2024 as an open standard for connecting LLM‑powered agents to external tools and data sources. Its original stateful version required a separate initialize request to obtain a session ID before any tool could be called, which added complexity and hindered scalability. Although MCP saw a surge of adoption in 2025, it was later overshadowed by Anthropic’s Skills framework, which offered a more flexible but less auditable alternative.

## [Ripgrep musl builds segfault on huge file trees due to allocator bug](https://github.com/BurntSushi/ripgrep/issues/3494) ⭐️ 7.0/10

Ripgrep compiled with musl libc occasionally crashes with a SIGSEGV when performing extremely large, concurrent directory searches, as reported in GitHub issue #3494 for version 15.2 on x86_64-unknown-linux-musl. The issue highlights reliability concerns for musl‑based systems such as Alpine Linux containers and HPC clusters, where ripgrep is often used for large‑scale code searches. The segfault occurs inside musl’s mallocng allocator during a calloc from opendir, triggered by heap‑metadata integrity assertions under high thread contention; swapping to alternative allocators like mimalloc or jemalloc can avoid the crash.

hackernews · Hacker News RSS · Aug 1, 12:34 · [Discussion](https://news.ycombinator.com/item?id=49133889)

**Background**: musl libc is a lightweight, standards‑conforming C library designed for static linking and frequent use in container‑oriented distributions such as Alpine Linux. Its default allocator, mallocng, uses a slab‑style bitmap approach optimized for low memory overhead but can exhibit contention under heavy multithreaded allocation patterns. Ripgrep is a fast, Rust‑based line‑oriented search tool that leverages parallel threads to scan large file trees, making it sensitive to allocator performance and stability.

Combining these ideas lets a model explore multiple hypotheses during training and retain only the most accurate one.
