## [研究者提出受睡眠启发的 LLM 记忆巩固机制](https://arxiv.org/abs/2605.26099) ⭐️ 8.0/10

一篇新的 arXiv 论文提出了一种受睡眠期间生物记忆巩固机制启发的 LLM 离线巩固方法，将近期上下文写入快权重状态（fast-weight states）。 该方法有望显著改善 LLM 的持续学习和长上下文记忆能力，解决模型在不进行昂贵重新训练的情况下难以保留和整合长期交互信息的关键局限。 该机制借鉴了快权重编程架构（fast-weight programming），即模型使用可快速更新的矩阵形式隐藏状态，并与近期关于睡眠时计算（sleep-time compute）的研究相呼应，后者允许模型在接收到查询之前离线处理和整合信息。

hackernews · Hacker News RSS · May 26, 15:36 · [社区讨论](https://news.ycombinator.com/item?id=48281226)

**背景**: 快权重编程器（Fast Weight Programmers, FWPs）是一类循环神经网络架构，使用二维矩阵形式的隐藏状态而非传统的向量形式状态，支持类似突触的快速权重更新，被认为是具有生物合理性的记忆模型。睡眠时计算（sleep-time compute）是指让 LLM 对累积的上下文进行离线计算，预先计算有用的表征，从而降低测试时的延迟和推理成本。睡眠中的生物记忆巩固是一个被广泛研究的现象，大脑在此期间重放信息并将其从海马体短期存储转移到皮层长期网络，本文直接受此过程启发。

## [甲基丙烯酸甲酯储罐事件凸显工业安全风险](https://www.science.org/content/blog-post/methyl-methacrylate-tank) ⭐️ 7.0/10

Science.org 上的一篇博客文章分析了一起涉及甲基丙烯酸甲酯储罐的真实事件，该事件几乎导致灾难性的 BLEVE（沸腾液体膨胀蒸汽爆炸），应急响应人员通过裂缝泄压及时干预，避免了灾难发生。 该事件凸显了工业化学品储存和应急响应准备方面的关键漏洞，尤其是在被动安全系统设计方面，并与历史上的金曼 BLEVE 和福岛等灾难进行了深刻类比，强调了基础设施失效可能带来的连锁风险。 甲基丙烯酸甲酯是一种易燃、具有刺激性的单体，用于塑料和树脂制造，具有吸入、皮肤和神经系统的危害，而这次近乎发生 BLEVE 的场景说明，过热加压液体的快速泄压可在毫秒内引发爆炸性汽化。

hackernews · Hacker News RSS · May 26, 19:25 · [社区讨论](https://news.ycombinator.com/item?id=48284712)

**背景**: BLEVE（沸腾液体膨胀蒸汽爆炸）是指装有高于大气沸点液体的压力容器发生灾难性失效，导致液体瞬间汽化并产生大规模蒸汽膨胀，从而引发毁灭性爆炸，如果物质易燃还会产生火球。1973 年的金曼 BLEVE 事件涉及一辆丙烷铁路罐车，造成 12 名消防员死亡，至今仍是危险品应急响应培训中的经典案例。甲基丙烯酸甲酯在压力下储存，如果不进行适当的抑制处理，可能发生放热聚合反应，这为容器失效的物理危害增加了热失控的风险。

## [Minicor（YC P26）发布面向遗留 Windows 系统的可扩展桌面 RPA 平台](https://www.minicor.com/) ⭐️ 7.0/10

Minicor 是由 Faiz 和 Saheed 创立的 Y Combinator P26 批次初创公司，发布了一个平台，使 AI 公司能够为缺乏 API 的遗留 Windows 应用程序构建和扩展桌面机器人流程自动化（RPA），尤其面向医疗健康和企业集成场景。该平台使用一个 MCP 服务器，让 Claude Code 或 Codex 能够操控运行桌面软件的虚拟机，生成基于 Python 的 RPA 工作流，可通过 API 触发，并提供完整的视频回放、日志记录和版本控制功能。 遗留桌面系统——尤其是医疗健康（EHR）、汽车、物流和金融服务领域的系统——通常缺乏 API，为试图进入这些行业的 AI 公司造成了重大集成瓶颈。Minicor 解决了大规模桌面 RPA 的核心挑战：高失败率（30% 以上）、可观测性差、编排复杂性以及可能每月产生数千张工单的级联故障。 Minicor 的工作流以 Python 脚本形式运行，以实现速度、成本效率和确定性，该平台还包含用于克隆虚拟机以并行化 RPA 执行的工具，支持处理 2FA/OTP 挑战，并支持人工介入步骤、Slack 通知以及通过截图进行基于 LLM 的虚拟机状态验证。基于 MCP 的架构使 AI 能够自主调试和修改 RPA 代码，所有变更均受版本控制。
