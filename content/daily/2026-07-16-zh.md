## [Firefox 通过 WebAssembly 编译并在 HTML 画布中运行](https://developer.puter.com/labs/firefox-wasm/) ⭐️ 6.0/10

整个 Firefox 浏览器（包括 Gecko、UI 以及 SpiderMonkey JavaScript 引擎）已被编译为 WebAssembly 并在 HTML <canvas> 元素中运行，采用 WISP 协议实现端到端加密，并引入实验性的 WASM→JS JIT 以提升速度。 表明 WebAssembly 能够承载如完整浏览器这样的复杂高性能应用，为基于 Web 的安全沙盒软件提供可能，并推动浏览器能够运行的边界。 该实现使用 WISP 协议在 WebSocket 上加密 TCP 流量，引入一种新颖的 WASM→JS JIT 以获得实验性能提升，开发成本据称超过 25 k opus/fable 代币；同时还提供了更轻量的 browser.js 替代方案。

**背景**: WebAssembly 是一种二进制指令格式，使得由 C/C++、Rust 等语言编译的代码能够在网页浏览器中以接近原生的速度运行。Firefox 的 Gecko 布局引擎和 SpiderMonkey JavaScript 引擎是负责渲染网页和执行 JavaScript 的核心组件。WISP 协议能够在单个 WebSocket 连接上代理多个 TCP/UDP 套接字，提供低开销的加密。JIT（即时编译）在运行时把 WebAssembly 翻译为 JavaScript 以提升速度。“浏览器中的浏览器”指的是在另一个浏览器内部运行一个浏览器，常用于沙盒或在受限系统上扩展功能。

**背景**: 基于体素的游戏引擎使用体素（三维像素）来构建 3D 世界，从而实现类似《我的世界》那样可修改的方块化环境。复古风格的开发环境模拟旧硬件的限制和美学，常提供低分辨率、有限调色板和简单脚本，以激发创造力。Lexaloffle 以其 PICO-8 虚拟主机而闻名，Voxatron 是其 3D 对应产品，继承了同样受限但易于上手的游戏制作理念。Voxatron 的 Alpha 版随附示例卡带以及用于设计关卡、精灵和音乐的工具套件，全部在其体素框架内运行。
