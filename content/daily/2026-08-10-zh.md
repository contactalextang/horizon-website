## [W3C 1998 年 '酷 URI 不会改变' 原则仍具现实意义](https://www.w3.org/Provider/Style/URI) ⭐️ 8.0/10

蒂姆·伯纳斯-李 1998 年的 W3C 指南《酷 URI 不会改变》在 Hacker News 上被重新讨论，凸显其持续倡导永久 URI 以确保网络资源长期可访问性。 该原则今天仍然至关重要，因为链接腐烂削弱了用户信任、SEO 和数字保存，证明稳定的 URI 是可靠网络架构的基础，尽管技术在不断演变。 该指南建议在 URI 中避免使用日期、作者、主题和文件扩展名以增强持久性，并指出虽然 301/302 重定向可以缓解问题，但它们不能替代从一开始就进行周密的永久 URI 设计的需求。

hackernews · Hacker News RSS · Aug 9, 14:32 · [社区讨论](https://news.ycombinator.com/item?id=49231809)

**背景**: URI（统一资源标识符）是用于标识网络上资源的字符串，其中 URL 是一种常见类型，用于定位网页。W3C 由蒂姆·伯纳斯-李创立，负责制定网络标准以确保互操作性和网络的长期可行性。《酷 URI 不会改变》原则于 1998 年提出，旨在应对由于网站重组和不良 URI 设计实践导致的链接腐烂问题日益突出的情况。

## [Project Oberon 系统移植到 RISC-V 架构](https://github.com/rochus-keller/OberonSystem/tree/op2-rv32) ⭐️ 7.0/10

一位开发者将 Project Oberon 系统从原来的 RISC-5 架构移植到 RISC-V，如其 GitHub 仓库分支所示。这保持了 Wirth 简单易懂计算系统的愿景，同时针对现代开放指令集架构。 此移植通过让 Oberon 在广泛采用且免版税的架构上运行，保存了 Niklaus Wirth 的极简计算理念。它支持在 RISC-V 日益普及的背景下，对可理解系统的教育和历史兴趣。 该系统可在低成本 FPGA 硬件上运行，如带有 1 MB SRAM 的 Xilinx Spartan-3，且移植位于 OberonSystem 仓库的 'op2-rv32' 分支。它保留了原始 Oberon 基于文本的用户界面和编译器。

hackernews · Rochus · Aug 9, 12:43 · [社区讨论](https://news.ycombinator.com/item?id=49230891)

**背景**: Project Oberon 由 Niklaus Wirth 设计，是一个完整的桌面计算机系统，包括操作系统、编译器和基于文本的用户界面，强调简单和可理解性。RISC-V 是一种开放标准的 RISC 指令集架构，由 UC Berkeley 在 2010 年开发，现由 RISC-V International 管理，因其免版税特性而在嵌入式和日益增长的通用计算领域得到采用。Wirth 一生倡导极简、优雅的系统，其思想影响了 Pascal 和 Oberon 等语言。
