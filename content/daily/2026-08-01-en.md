## [Go Team Proposes Generic Set and OrderedMap for Container Package](https://github.com/golang/go/issues/80590) ⭐️ 8.0/10

The Go team has submitted a proposal (issue #80590) to add generic collection types such as Set[E] and OrderedMap[K,V] to the standard library's container package. This addresses a long‑standing gap in Go’s standard library, allowing developers to use built‑in, type‑safe sets and ordered maps without relying on third‑party packages. The proposal defines Set[E] as a map[E]struct{} and OrderedMap[K,V] using a hash map for lookups plus a doubly linked list to preserve insertion order, both leveraging Go 1.18+ generics.

hackernews · Hacker News RSS · Jul 31, 18:39 · [Discussion](https://news.ycombinator.com/item?id=49127031)

**Background**: Go introduced generics in version 1.18, enabling type‑safe parameterized types. Prior to this, the container package only offered non‑generic data structures such as list, ring and heap. Developers have long relied on third‑party libraries for sets and ordered maps, which the new proposal aims to replace with standard‑library equivalents.
