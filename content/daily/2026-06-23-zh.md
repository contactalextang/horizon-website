## [Linux Secure Boot 证书将在 2025 年到期](https://lwn.net/Articles/1029767/) ⭐️ 8.0/10

LWN 文章警告，用于为 Linux shim 引导加载程序签名的 Microsoft UEFI CA 证书将在 2025 年到期，并概述了管理员必须采取的更新证书以避免启动失败的步骤。 因为大多数 Linux 发行版依赖此由 Microsoft 签名的 shim 来启用 Secure Boot，其到期将导致受影响的系统无法启动，除非提前更新信任链。 管理员需要用 Microsoft UEFI CA 2023 密钥替换过期的 UEFI CA，更新 shim 和 GRUB 二进制文件，并确保有足够的连续 efivar 空间来存放新变量。

hackernews · Hacker News RSS · Jun 22, 18:24 · [社区讨论](https://news.ycombinator.com/item?id=48633941)

**背景**: UEFI 安全启动依赖于微软 UEFI 证书颁发机构（CA）的信任链，该机构为 shim 引导加载程序签名，而 shim 再为 GRUB 引导加载程序和 Linux 内核签名。shim 使得 Linux 发行版能够在不让用户注册自定义密钥的情况下启用 Secure Boot。当微软 UEFI CA 证书到期时，shim 上的签名将失效，信任链断裂，除非安装新的受信任 CA，否则会导致启动失败。

## [Deno Desktop 框架实现跨平台 GUI 应用](https://docs.deno.com/runtime/desktop/) ⭐️ 8.0/10

Deno Desktop 作为 Deno v2.9.0 的一部分发布，提供了一个使用 Deno 构建跨平台桌面应用的框架，具备共享的 Chromium Embedded Framework (CEF) 运行时后端，并深度集成了 Deno 的权限系统。 通过在多个应用之间共享单个 CEF 运行时，Deno Desktop 能够将每个应用的二进制体积降至几兆，并提供一种具备权限感知的 Electron 替代方案。 该框架支持 CEF、Webview 和 Raw 三种后端，需要使用 Deno canary 频道才能试用，并在编译时将授予的权限烘焙进二进制文件，尽管可以通过 --prompt 标志启用运行时权限提示。

hackernews · GeneralMaximus · Jun 22, 05:38 · [社区讨论](https://news.ycombinator.com/item?id=48626137)

**背景**: Deno 是一个现代的 JavaScript 和 TypeScript 运行时，以其基于能力的权限系统著称，默认拒绝所有特权访问，必须通过命令行标志或运行时提示显式授予。Chromium Embedded Framework (CEF) 是一个开源项目，使得开发者可以在原生应用中嵌入基于 Chromium 的浏览器，从而使用 HTML、CSS 和 JavaScript 构建用户界面。Deno Desktop 在这些基础之上提供了共享的 CEF 运行时，并将 Deno 的权限模型集成进来，以简化跨平台桌面应用的开发。
