## [Chromium 148's Math.tanh Change Enables OS-Level Browser Fingerprinting](https://scrapfly.dev/posts/browser-math-os-fingerprint/) ⭐️ 8.0/10

Starting with Chromium 148, the V8 engine computes Math.tanh using the host operating system's libm instead of its bundled fdlibm implementation, causing the function to return OS‑specific floating‑point values. This change creates a new, reliable fingerprinting vector that can expose a user's underlying OS even when the user‑agent string is spoofed, raising privacy concerns for anti‑bot and tracking systems. Only Math.tanh is affected; other JavaScript Math functions continue to use the OS‑independent fdlibm port, and the difference can be detected with a single call on a carefully chosen input value.

hackernews · Hacker News RSS · Jul 12, 21:12 · [Discussion](https://news.ycombinator.com/item?id=48884853)

**Background**: Browser fingerprinting collects subtle differences in how a browser executes code to uniquely identify users. The JavaScript Math.tanh function computes the hyperbolic tangent, and until Chromium 148 V8 used its own fdlibm port, giving identical results on all operating systems. Starting with Chromium 148, V8 delegates the calculation to the host system's libm library, which can produce slightly different bit patterns on Windows, macOS, Linux, etc., exposing the underlying OS.

## [Warning Against the One-Step Trap in AI Research](http://incompleteideas.net/IncIdeas/OneStepTrap.html) ⭐️ 7.0/10

The article "The One-Step Trap (in AI Research)" published on Richard Sutton's incompleteideas.net site warns researchers that focusing only on immediate, one-step predictions undermines long-term learning and progress in AI. Recognizing this trap is crucial because it steers AI research toward more effective temporally abstract models, which can improve reinforcement learning agents' ability to plan and generalize over extended horizons. The article explains that one‑step models are appealing yet hopeless, widely used in POMDPs, Bayesian analysis, control theory, and compression theories, and recommends building temporally abstract models with options and General Value Functions (GVFs) as described in Sutton et al., 1999.

rss · Hacker News RSS · Jul 12, 18:41

**Background**: In reinforcement learning, agents learn to predict future rewards by estimating value functions; a one‑step update uses only the immediate reward and the value of the next state. Temporal abstraction extends this idea by allowing predictions over multiple steps at once, using constructs such as options (temporally extended actions) and General Value Functions (GVFs) that summarize long‑term dependencies. The one‑step trap occurs when researchers mistakenly believe that all necessary knowledge can be captured by repeatedly applying one‑step updates, ignoring the benefits of direct multi‑step modeling.
