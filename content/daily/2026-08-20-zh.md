## [Go 1.27 发布：支持泛型方法、uscale 浮点解析、后量子密码学及标准 uuid 包](https://go.dev/blog/go1.27) ⭐️ 8.0/10

Go 1.27 引入泛型方法，使用 Russ Cox 的 uscale 算法改进浮点数解析，添加 crypto/mldsa 以支持后量子签名，并将 uuid 包纳入标准库。 此版本提升了开发者的人体工程学、数值可靠性和未来安全性，同时减少对第三方 UUID 库的依赖，惠及整个 Go 生态。 泛型方法允许在方法上声明类型参数，便于链式 API；uscale 算法提升 strconv.ParseFloat/FormatFloat 的速度和正确性；crypto/mldsa 实现 ML‑DSA（FIPS 204），提供 MLDSA44/65/87 三种参数集；uuid 包取代 github.com/google/uuid 成为标准库的标准实现。

hackernews · Hacker News RSS · Aug 19, 18:33 · [社区讨论](https://news.ycombinator.com/item?id=49365405)

**背景**: 在 Go 1.27 之前，类型参数只能用于函数和类型，不能用于方法，这限制了可重用的泛型代码。Go 的浮点数解析长期依赖于在速度和准确性之间权衡的旧算法；uscale 算法提供了更快、更准确的解决方案。后量子密码学通过实现 ML‑DSA（一种 NIST 标准化的签名方案）为 Go 未来的安全威胁做好准备。最后，将 uuid 移入标准库结束了因广泛使用的 google/uuid 包而造成的多年碎片化。

## [Dave Rupert 介绍 MicroLighter，一个轻量级语法高亮工具](https://daverupert.com/2026/08/microlighter/) ⭐️ 5.0/10

Dave Rupert 宣布了 MicroLighter，一个零依赖的 JavaScript 语法高亮工具，利用 CSS Custom Highlight API 为网页上的代码块上色。 MicroLighter 体积极小且使用原生浏览器高亮，减少对庞库的依赖，提升需要轻量代码片段的网站性能。 该工具读取 TextMate 语法，利用浏览器的正则引擎匹配标记，并将每个标记范围注册为 CSS 高亮；发布为单个 microlighter.min.js 文件（约 2 KB gzipped）。

rss · Hacker News RSS · Aug 19, 18:28

**背景**: 语法高亮通常通过 JavaScript 库（如 Highlight.js 或 PrismJS）实现，它们会向代码块添加额外的标记和样式。近年来，一些方案利用 CSS Custom Highlight API，让浏览器直接渲染高亮范围而无需额外的 DOM 节点。MicroLighter 采用此模式，使用 TextMate 语法对代码进行标记，并依赖浏览器原生正则引擎应用 CSS 高亮。
