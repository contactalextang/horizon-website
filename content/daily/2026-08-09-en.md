Triton is a newly released open-source DirectX 11 driver for QEMU that enables improved 3D graphics performance in Windows virtual machines running on Linux hosts, utilizing the VirtIO graphics path instead of DLL substitution. This development addresses a long-standing gap in open-source virtualization by providing native DirectX 11 support for Windows guests in QEMU, improving usability for gaming and graphics-intensive workloads on Linux hosts without relying on proprietary solutions. Triton works alongside the Neptune driver to deliver full DirectX 11 functionality, is currently experimental and requires custom builds, and was partially developed using AI assistance from Claude Opus 5 and Claude Fable 5.

Solutions like Looking Glass and LibVF.IO aim to improve VM graphics performance, but open-source DirectX-level support in QEMU has been lacking until now.
