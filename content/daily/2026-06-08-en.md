## [Linear's Speed Secrets: Optimistic UI and Background Sync Explained](https://performance.dev/how-is-linear-so-fast-a-technical-breakdown) ⭐️ 7.0/10

The article details how Linear uses optimistic UI updates and background synchronization to create a perception of speed, while community comments debate its real‑world performance and UX trade‑offs. It highlights frontend techniques that improve perceived responsiveness and illustrates the consistency‑vs‑latency trade‑off that developers must consider when building collaborative apps. Linear assumes client mutations succeed immediately, updates the UI optimistically, and later reconciles changes with the server via a background sync process that follows an eventual consistency model.

hackernews · Hacker News RSS · Jun 7, 19:01 · [Discussion](https://news.ycombinator.com/item?id=48437609)

**Background**: Optimistic UI is a pattern where the interface updates instantly assuming a server request will succeed, rolling back if it fails (as shown by React’s useOptimistic hook). Background synchronization lets web apps defer network requests to a service worker, enabling offline‑first updates when connectivity returns. Eventual consistency guarantees that, given no further updates, all replicas will converge to the same value over time, but may show stale or conflicting reads during the convergence period.
