## [OpenAI 首次发布与博通合作的定制 AI 推理芯片 Jalapeno](https://techcrunch.com/2026/06/24/openai-unveils-its-first-custom-chip-built-by-broadcom/) ⭐️ 8.0/10

OpenAI 宣布了其首款定制 AI 推理芯片 Jalapeno，该芯片由 Broadcom 共同开发、由 TSMC 制造，宣称相比典型 GPU 可节省约 50% 的成本。 此举表明 OpenAI 正转向内部硬件优化，以减少对第三方 GPU 的依赖并降低大规模语言模型服务的运营成本。此外，这也凸显了 AI 公司日益倾向于设计专用推理 ASIC 以提升效率和可扩展性的趋势。 Jalapeno 芯片是一种专为 LLM 推理优化的 ASIC，开发历时九个月，期间使用 OpenAI 的模型加速了部分设计工作，并将由 TSMC 采用先进制程制造。Broadcom 提供了定制设计专长和 IP，而 OpenAI 预计该芯片相比当前基于 GPU 的推理方案可降低约 50% 的每 token 成本。

hackernews · Hacker News RSS · Jun 24, 17:47 · [社区讨论](https://news.ycombinator.com/item?id=48663324)

**背景**: AI 推理芯片是专门的 ASIC，旨在优化模型服务时的每 token 成本、延迟和功耗，与侧重原始 FLOPs 和内存带宽的训练芯片不同。Broadcom 在定制 AI ASIC 设计方面处于领先地位，与超大规模云服务商合作生产高复杂度的 XPU。TSMC 使用其领先的制程技术制造这些芯片，实现高密度和高性能。向推理导向硬件的转变反映了在已部署的 AI 系统中，推理工作负载远远超过训练运行的事实。

## [NVIDIA 的 45°C 液冷设计将数据中心用水削减至近零](https://blogs.nvidia.com/blog/liquid-cooling-ai-factories/) ⭐️ 8.0/10

NVIDIA 宣布了一种在 45 °C 下运行冷却液的液冷架构，使 AI 数据中心能够在保持芯片性能的同时实现近零用水冷却。 降低用水量可以缓解超大规模设施的可持续性压力，并可为运营商每年节省数百万美元的水电费，使 AI 基础设施更加环保且经济。 该设计采用温水作为热传递介质，消除了蒸发损失；工程估算显示，一个 50 MW 的超大规模数据中心每年可节省超过 260 万加仑的水以及超过 400 万美元的水电费用。

**背景**: 传统数据中心冷却依赖蒸发式冷水机，尤其是在炎热气候中会消耗大量水资源。温水冷却将冷却液温度提升至约 45 °C，使热量能够在不蒸发的情况下被排出，并使水能够在闭环系统中循环使用。NASA 艾姆斯研究中心的模块化超算设施表明高进水温度同样高效，且该方案还可与区域供热结合，为附近社区提供有用的热量。

## [Rust 社区致力于移除 crates.io 发布对 GitHub 的依赖](https://infosec.exchange/@mttaggart/116806641273303255) ⭐️ 8.0/10

Rust 社区已合并 RFC #3963 以解除移除 GitHub 作为 crates.io 发布强制依赖的障碍，实现工作已经开始。志愿者正在通过 rust-lang/crates.io 仓库推进此工作。 减少对 GitHub 的依赖可以降低中心化风险和单点故障问题，使 Rust 生态的 crate 发布更具弹性，并符合开源去中心化的原则。 合并的 RFC 是 rust-lang/rfcs#3963，相关工作在 rust-lang/crates.io issue #326 中跟踪，列出了需要志愿者贡献的路线图任务。目前没有官方资金，进展依赖于志愿者。

hackernews · Hacker News RSS · Jun 24, 19:40 · [社区讨论](https://news.ycombinator.com/item?id=48664733)

**背景**: crates.io 是 Rust 的默认包注册表，Cargo 用它来发布和下载 crate。目前，发布工作流程经常依赖 GitHub Actions 或 GitHub 身份验证，从而对 GitHub 的可用性产生依赖。Rust 项目主要由志愿者驱动，基础设施任务的资金来自社区支持，缺乏固定资助。
