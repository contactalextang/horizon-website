Although originally intended for widespread use, ENUM adoption has been limited, leaving the e164.arpa zone sparsely populated and poorly monitored.

## [What happens when a GPU reads memory](https://blog.doubleword.ai/what-happens-when-a-gpu-reads-memory) ⭐️ 8.0/10

The article walks through the exact sequence a GPU follows to read memory, starting with virtual‑to‑physical address translation via TLBs, then moving through L1 and L2 caches, and finally accessing DRAM with coalescing and row‑buffer effects. Understanding these low‑level mechanics helps systems and graphics programmers optimize kernels, predict latency, and tune AI workloads that are memory‑bound. It highlights that NVIDIA does not publish full TLB and cache timing details, so the author derives them from hardware timing experiments; it also notes that AMD’s ISA documentation can be used as an alternative reference.

hackernews · Hacker News RSS · Aug 21, 16:16 · [Discussion](https://news.ycombinator.com/item?id=49390308)

**Background**: Modern GPUs use a memory hierarchy that includes per‑SM L1 caches, a shared L2 cache, and high‑bandwidth DRAM (HBM/GDDR6). Virtual‑to‑physical address translation is accelerated by translation lookaside buffers (TLBs) that cache recent page‑table entries. When many threads request nearby addresses, the memory controller coalesces the requests into fewer DRAM bursts, improving bandwidth utilization.
