## [在多个 Tenda 路由器固件版本中发现隐藏的身份验证后门](https://kb.cert.org/vuls/id/213560) ⭐️ 8.0/10

安全研究人员在多个 Tenda 路由器固件版本中发现了一个隐藏的管理员后门，该后门使用硬编码密码'rzadmin'绕过身份验证，通过 Web 管理界面获得管理员访问权限。 该后门使未经身份验证的攻击者能够完全控制受影响的路由器，对依赖这些广泛部署设备的家庭和企业网络构成严重威胁。 该漏洞影响多个固件版本，暴露了固定的硬编码凭证'rzadmin'，已被分配 CVE-2026-11405，并允许在无需任何身份验证的情况下远程获得管理员访问权限。

hackernews · Hacker News RSS · Jul 8, 00:08 · [社区讨论](https://news.ycombinator.com/item?id=48825749)

**背景**: 深圳市腾达科技有限公司是一家生产家庭和商业网络设备（如路由器、交换机和无线接入点）的中国厂商。路由器固件是嵌入设备中的软件，负责管理设备操作并提供基于 Web 的管理界面。隐藏的身份验证后门是指未文档化的凭证或机制，攻击者可利用它绕过正常登录流程并获得管理员权限。

## [sqlite-utils 4.0 发布，加入数据库架构迁移、嵌套事务和复合外键支持](https://simonwillison.net/2026/Jul/7/sqlite-utils-4/#atom-everything) ⭐️ 8.0/10

Simon Willison 发布了 sqlite-utils 4.0，新增了通过 Migrations 类实现的数据库架构迁移、通过 db.atomic() 方法的嵌套事务以及复合外键支持。 这些功能为 SQLite 开发者提供了内置的迁移能力和更安全的事务处理，减少了对外部工具的依赖，并在使用 Datasette 或 sqlite-utils 库的项目中简化了架构演变。 迁移通过 Python 文件定义，使用 table.transform() 方法重建表以实现 SQLite ALTER TABLE 不支持的更改；嵌套事务通过 db.atomic() 依赖保存点；复合外键支持多列外键约束；该版本还包含在升级指南中记载的破坏性更改。

rss · Simon Willison · Jul 7, 19:32

**背景**: SQLite 是一种轻量级的文件关系数据库，原生缺少架构迁移工具，开发者通常需要手动编写 ALTER TABLE 语句或依赖第三方库。SQLite 本身不支持嵌套事务，但可以通过保存点（savepoint）来模拟，从而在更大的事务内实现部分回滚。复合外键（也称为组合外键）允许子表同时引用父表的多个列，以实现更复杂的参照完整性约束。sqlite-utils 是一个广泛使用的 Python 命令行工具和库，常与 Datasette 一起用于数据的发布和探索。
